# DraftPound

DraftPound orchestrates distributed-transactions, providing adaptive scaling and auto-replication for robust service reliability and real-time data consistency.

With DraftPound, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftPound.git`
2. `cd DraftPound`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
